# 関係者への目配り・言葉づかい・ネガティブな事実

公式記事は、候補者だけでなく、社員・取引先・話し手本人・その家族も読む。全員が読んだときに、誰も置いていかれない書き方にする。

---

## 1. 読む人ごとの確かめ方

| 読む人 | 確かめる問い | 当たりやすい負け筋 |
|---|---|---|
| 社員（記事に出ない人） | 自分たちが「運用係」「力不足」に見えないか。挑戦の外に置かれていないか | A1・A2・A3 |
| 話し手本人 | 自分の言葉だと思えるか。ためらった話題が載っていないか | C1・C3・B6 |
| 経営者・決裁者 | 過去の会社が無策に見えないか。言い切れない宣言をしていないか | B1・B2・B5 |
| 取引先・パートナー | 事業を支える外の人に触れているか。下に見ていないか | A6 |
| 候補者 | 迎えたい人が「面白い」と思うか。きれいすぎて別の人が来ないか | B3・D13 |
| 前の記事の読者 | 前の記事と食い違っていないか | C6・F2・E7 |

## 2. 意図しない分断・比較を見つける

- 対になりやすい言葉が同じ記事に出たら、読み直す：新しく加わった／これまでの、中途／生え抜き、経験者／未経験、若手／ベテラン、本社／現場。
- 一部の人だけが優秀に見える並べ方になっていないか（成果を語るのがいつも同じ属性の人）。
- 直し方の原則（資料A A1〜A3）：
  - 主語を会社・組織・全員にする
  - 人が加わったことは「補強」として一度だけ書く
  - 求めることは「入社の時期や立場を問わず、全員に共通」と書く
  - 比較をやめる。事実は残し、比べる言葉だけを外す

### 例（架空）
- 直す前：「中途で入った営業が新しい販路を開き、既存の社員は従来の顧客を守ってきた。」
- 直した後：「この 2 年で、新しい販路を開くことと、従来の顧客を守ることの両方に手を打てる体制になった。新しい販路の一つは、昨年加わった営業が担当している。」
- 残した事実：新しい販路を開いた・担当者が昨年加わった人。外した言葉：既存の社員を「守る側」に置く対比。
- 副作用：担当者個人の手柄が見えにくくなる。本人の記事なら、本人の判断を具体で書けば足りる。

## 3. 言葉づかい

- 敬語は「誰が・誰について・誰に向けて」話すかで決める（`references/derived/A_classification.md` 6-1）。
  - 経営者・管理職が自社の社員について話すとき、社員を敬語の対象にしない（「加わっていただき」→「加わり」）
  - 顧客・取引先・パートナーには敬語を使う
  - 候補者を指す「方」は使ってよい
- 呼び方を一つに決め、揺らさない（負け筋 G1）。決めたら台帳の `rules` に入れる。
- 先方の表記規定・前の記事の表記を優先する（6-6）。

## 4. ネガティブな事実の扱い

ネガティブな事実を黙って消さない。消すと、記事がきれいすぎて信用されなくなり（B3）、事実の改変にもなる。

1. **まず事実を確かめる**：何が・いつ・どの範囲で起きたか（fact-checker）。
2. **意図した判断として書けるか考える**：「できなかった」ではなく「限られた体制のなかで、何を優先したか」（B1）。
3. **状態として書けるか考える**：「難しくなった」ではなく「判断の精度がこれまで以上に求められる」（B2）。ただし、言い換えで事実が薄まりすぎないか確かめる。
4. **書けないとき**：消すか残すかを書き手が決めない。決裁者に、事実と選択肢（残す・書き方を変える・載せない）を示して判断を仰ぐ。決まったことは台帳の `decisions` に書く。
5. **本人がためらった話題は使わない**（B6）。

## 5. 誇張と宣言

- 「業界一」「唯一」「必ず」「失敗ゼロ」は、資料で確かめられ、公開の了承があるときだけ（B5・C4）。
- 未来の約束は、節目や基準として書く（「2030 年という節目に向けて」）。
- 一人の事例を、誰にでも起きる結果のように見出しにしない（承認済みルール）。

## 6. 公開してよいかの確認

- 社内の数字、施策名、次の事業、会議の名前、株主や資本の話、出したくない事業構造は、載せる前に確認に回す（B6・B7）。
- 公開しないと決まった語は台帳の `confidential` に入れる。`aco ledger <slug> check` と `aco audit --project <slug>` が原稿に出たら止める。
