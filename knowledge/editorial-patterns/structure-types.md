# 章立ての型

型は出発点で、正解ではない。目的と一番の印象（`projects/<slug>/work/01_brief.md`）を先に決め、そのあとで型を選ぶ。型の章に根拠のある素材がなければ、その章は削るか要取材にする。空いた章を一般論で埋めない。

- 型の使い方と例外の考え方：`references/derived/A_classification.md` 6-2
- 並べ方の原則（理由→結論、全体→具体、変化→仕組み、山場は終盤）：資料A 第1部 6。例外は `references/derived/A_classification.md` 6-3

---

## 1. 資料A の 4 型

### 経営者インタビュー（事業）
1. 現在地（どの位置にいるか、何で築いたか）
2. 成長の余地（市場、まだ届いていない所）
3. 打ち手の転換（何をどう見直したか）
4. それを支える基準（品質・判断の軸）
5. 次の展開（後編・次の記事への橋渡し）

### 経営者インタビュー（組織）
1. 組織の変化（何が補強されたか）
2. 一つになれた理由（共通の軸・仕組み・データ）
3. 事業の局面と注力テーマ（なぜいま、何に）
4. 変化の進め方（日々の仕組みを守りながら変える仕組み）
5. 求めること（全員向けの行動基準）
6. 文化の象徴となるエピソード（山場）
7. これから加わる方への期待

### 社員インタビュー
1. 入社前の経歴と、入社のきっかけ
2. いまの仕事の中身（具体的な一日・一件）
3. 壁と、それをどう越えたか（意図した工夫として書く）
4. この会社らしさを感じた場面
5. いまのやりがいと、これから
6. 候補者へのメッセージ（どんな人が合うか）

### プロジェクト・カルチャー記事
1. 何の取り組みか
2. なぜ始めたか
3. 今回変えたこと
4. 周りをどう巻き込んだか
5. 反応・数字（前回と比べて）
6. 思わぬ効果（関わった人の声）
7. 学びと、合う人物像

## 2. ほかの記事の型（編集部の追加）

### 会社紹介（事業紹介）
1. 何をしている会社か（一文で。誰の、どんな困りごとを、どう解くか）
2. その仕事が実際に役立っている場面（一件の具体）
3. 他社と違うやり方（判断の基準・仕組み）。比較の相手を貶めない
4. それを支える人と組織
5. いまの局面と、これから必要な人
- 注意：「どの会社にも当てはまる紹介」になりやすい（AI-05）。1 章で一つの具体（顧客の業種・数・場面）が出せないなら、記事の形式を考え直す

### 職種紹介
1. この職種が会社の中で担うこと（誰から何を受け取り、誰に何を渡すか）
2. ある一日・ある一件（時系列で）
3. 判断が要る場面と、その基準
4. 難しさと、それを越えるための仕組み・支援
5. 向いている人（経験より、ものの見方で書く）
- 注意：社員インタビューと混ぜると、どちらも薄くなる。主役が「職種」か「人」かを先に決める

### 対談・座談会
1. この組み合わせで話す理由（何が違う二人・三人か）
2. 共通の問い（全員が答える一つの問い）
3. 見方が分かれる所（分かれ方そのものが読みどころ）
4. 一つの出来事を、立場の違う目で語る（山場）
5. 読者への一言（一人ずつ、短く）
- 注意：全員が同じことを言わない（負け筋 E4）。話す範囲を分けるか、後の人が一歩足す。一人だけが優秀に見える並べ方をしない（A3）

### 代表メッセージ・短いメッセージ（ホームページ）
- 見出し 1 行＋本文 250 字前後。具体例は 1〜2 個（`knowledge/approved-lessons/lessons.json` の承認済みルール）
- 記事の型を当てはめない。エピソードを並べず、一つの具体と一つの約束（根拠のある範囲）で書く

### ルポ・ドキュメント（取材者の目で書く記事）
1. 場面から入る（取材者が見たこと）
2. その場面の意味を、話し手の言葉でほどく
3. 時間をさかのぼる（なぜそうなったか）
4. 現在に戻り、変わったこと・変わらないこと
5. 最初の場面を、別の意味で見直して終える
- 注意：地の文が主役になる。取材者の解釈は解釈として書き、話し手のセリフにしない

## 3. 型を使わない判断

次のどれかに当たるときは、型を使わず、素材の筋から章を組む。

1. **素材に型より強い筋がある**：一つの出来事の時系列、一つの判断の前と後、一つの失敗と立て直しなど。筋そのものが記事の発見なら、型に分解すると発見が消える。
2. **型の章の半分以上に根拠のある素材がない**：型を埋めるために一般論を書くことになる。
3. **シリーズの前の記事が別の構成で、そろえる必要がある**：前の記事の構成を型として扱う。
4. **媒体の決まった形式がある**：媒体のフォーマットに従う。

型を使わないときも、次の検査（資料A 第1部 9）は必ず通す。

- 一番の印象に関係しない章はないか
- 同じことを二つの章で言っていないか
- 全章の主語が特定の人たちになっていないか
- 山場はどこか。終盤にあるか（例外は `references/derived/A_classification.md` 6-3）
- リードの問いと締めが対応しているか
- 前の記事と同じ問いを繰り返していないか

## 4. 構成を決めたら書くこと（`projects/<slug>/work/04_structure.md`）

- 章ごとに：見出し案／その章が一番の印象にどう効くか（一行）／使う素材の No.／問いの案／字数の目安
- 型を使ったか、使わなかったか。使わなかったなら理由
- 山場の章と、その根拠になる素材
- リードの問いと、締めで回収する言葉
