# 発言の整文：許すこと・許さないこと

話し手のセリフに入れてよいのは、話し手が実際に言ったことだけ。整文は「読める形にする」作業で、「言わせたいことを言わせる」作業ではない。

- `python3 scripts/aco quotes <原稿> --transcript <書き起こし>` が、記事の発言を書き起こしと照合して A〜E で判定する。D（根拠なし）・E（数値・固有名の不一致）は必ず直す。
- 判定の考え方：A＝ほぼ原文／B＝整文・要約で要素が一致／C＝言い換えで意味や範囲が変わった可能性（要確認）。

---

## 1. 許すこと

| すること | 書き起こし（架空） | 整文した発言 |
|---|---|---|
| 言いよどみ・つなぎの言葉を削る | 「えーと、あの、まあ、最初はですね、測り直すのは、ちょっと面倒だなと」 | 「最初は、測り直すのは面倒だと思っていました」 |
| 同じ言葉の重複を削る | 「全部、全部測るんです、全部」 | 「全部測るんです」 |
| 語順を整える（意味を変えない範囲） | 「やめたんですよ、去年。夜勤のときの手書きの記録」 | 「去年、夜勤の手書きの記録をやめたんです」 |
| 話が飛んだ所を、同じ話題の中で並べ直す | 2 つの話題が交互に出る | 話題ごとにまとめる（並べ直したことを source-audit にメモ） |
| 指示語を、本人が指していたものに戻す | 「あれを入れてから」（直前に「温度ロガー」と話している） | 「温度ロガーを入れてから」 |
| 文を分ける | 一文が長く続く | 句点で分ける（言葉は変えない） |
| 媒体のトーンに合わせて文末をそろえる | 「〜なんすよ」 | 「〜なんです」（台帳で口語の扱いを決めた範囲で。`references/derived/A_classification.md` 6-7） |

## 2. 許さないこと

| しないこと | 例（架空） | なぜ |
|---|---|---|
| 言っていない主張を足す | 書き起こし「測り直すのは面倒でした」→記事「面倒でしたが、それこそが品質を守る誇りだと気づいたんです」 | 話していないことをセリフにしている（負け筋 C1） |
| 数値・固有名を足す・変える | 書き起こし「かなり減りました」→記事「不良が 3 割減りました」 | 根拠のない数字（負け筋 C4）。数字が要るなら本人に確かめる |
| 評価語・形容を足す | 「変えました」→「大きく変えました」「画期的な仕組みに変えました」 | 言い過ぎ（C4・AI-01） |
| 範囲を広げる・狭める | 「うちの課では」→「当社では」 | 意味が変わる（C3）。「全員」と「一部」を入れ替えない |
| 因果を足す | 「点検表を変えました」「夜勤が楽になりました」（別々に話した）→「点検表を変えたので、夜勤が楽になりました」 | 推測で因果をつなぐ（C7） |
| 取材の後の出来事を言わせる | 取材は 6 月、出来事は 9 月 | 取材のセリフにしない（C2） |
| 話し手の口調を消す | 考えながら話す人の言葉を、決め台詞の連続にする | 全員が同じ優等生になる（AI-14、`philosophy/human-writing.md`） |
| 書き手の解釈を本人の言葉にする | 地の文で書くべき分析を「〜だと考えています」とセリフにする | 情報の区別が崩れる（`philosophy/editorial-principles.md` 3 章） |
| 二人の発言を一人にまとめる | 座談会で別の人の言葉を混ぜる | 誰の発言か分からなくなる |

## 3. 迷ったとき

- 書き起こしの言葉を並べ、整文した文と見比べる。足した名詞・数字・形容・接続詞が一つでもあれば、それは整文ではなく創作。
- 本人に言ってほしい内容があるなら、セリフにせず、追加取材で聞く（`knowledge/editorial-patterns/interview-craft.md` 4 章）。
- 整文で大きく並べ替えた発言は、`【要確認：本人の確認】` を付けて、本人の確認に回す。
- 先方から「この言い方にしてほしい」と言われたら、本人の確認を経た表現として台帳の `approved` に入れ、誰がいつ了承したかを残す。

## 構成を組み直すときの扱い

- **問い**：問いは聞き手の言葉なので、整えたり足したりしてよい。ただし、答えとかみ合う範囲にとどめ、聞き手が言っていない前提や評価（「〜という強みがありますね」など）を入れない（負け筋 E1・E2）。
- **一つの答えを章をまたいで分ける**：分けてよい。ただし、分けたことで文脈が変わらないこと、時系列を偽らないこと。分けた所は `v<N>_notes.md` に「元の発言の位置 → 置いた章」を書く。
- **書き起こし以外の発言**（取材メモ・人づての話・資料の引用）：「」でセリフにする前に、本人の言葉として出してよいかを確かめる。確かめるまでは地の文で事実として書くか、【要確認】を付ける（負け筋 C1）。
- **表記ルールの置き換え**：案件の台帳で決めた言い換え（例：仲間→メンバー）はセリフにも当ててよい。照合は `python3 scripts/aco quotes … --project <slug>` で行う（言い換えを戻して照合する）。
