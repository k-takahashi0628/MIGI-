## シナリオテストの実行方法

- 6 本とも、この会話の文脈を持たない新しい分身（サブエージェント）に、リポジトリの `CLAUDE.md`・各シナリオの `README.md`・エージェント定義・スキルだけを読ませて実行した。採点スクリプト（`verify.py`）と対照（`controls/`）は読ませていない。
- サブエージェントは別のサブエージェントを呼べないため、手順の中の「〇〇エージェントに頼む」は、その分身がエージェント定義とスキルを読んで役を順に演じた。**Claude Code 本体がエージェントを別々に呼び出す形での実行は未確認**（同梱の CLI が単体ではログインしていなかったため）。
- 採点：`python3 tests/scenarios/run.py outputs`

## テストで見つかり、直したこと

| 見つかった問題 | 見つけたテスト | 直したこと |
|---|---|---|
| `aco audit --final` が中身つきの印（【要取材：…】）と HTML コメントを見逃す | A・C | 印は中身つきも止める。清書に残った HTML コメントも止める。作業稿では印の中身を兆候として数えない |
| 表記ルールで言い換えたセリフ（仲間→メンバー）が `aco quotes` で E になる | F | `quotes --project <slug>` で台帳の言い換えを戻して照合する |
| 最後の答えのあとに地の文を置く書き方がない | F | 区切りの行（`---` `＊` `◆`）で地の文に戻る決まりを追加（設計書 §9・スクリプト） |
| 「第3章の見出しだけ」を番号で指定できない | D | `scope --allow chapter-heading:3`（と `chapter:3`）を追加 |
| 原稿の先頭の版情報コメントが「一文字も変えない」とぶつかる | D | 版情報は原稿に書かず、`history.md` と `v<N>_notes.md` に書く決まりに統一 |
| 範囲があいまいなときの扱いがエージェントとスキルで違う | D | 「狭く取って直し、確認を一つ返す」に統一 |
| 修正表の列が `aco revtable` とひな形で違う | D | 出力をひな形の列（場所／今／直し／どうしたか／当たった負け筋／理由）にそろえた |
| 案件フォルダのない単発の作業で `ledger brief` が止まる | B・D・E | 全体ルールだけを出して続ける。単発の作業の置き場所を CLAUDE.md と article-desk に追加 |
| 字数の指定と素材の量がぶつかったときの決まりがない | B・C・F | 「根拠のある素材＞字数の指定＞シリーズの釣り合い」。届かなければ埋めずに追加取材を出す |
| 地の文の数値を素材と照合する手段がない | B | `aco numbers <記事> --source <素材>` を追加 |
| 書き起こし冒頭のメタ情報（会社・取材日など）を発言として読む／取材メモの「名前「…」」形を読めない | B・E | メタ情報を除外し、「名前「…」」形も読む |
| 山場の位置の言い方が場所によって違う | C | 「章の順で数えて後半 3 分の 1（最後の問いの手前が基本）」に統一 |
| 問いの書き換え・答えの分割・メモからの発言の扱いが決まっていない | B・C・A | `knowledge/editorial-patterns/quote-editing.md` に追加 |
| 全体ルール GL-009 が、特定の案件の「口語は絶対 NG」に寄っていた | B | 「媒体のトーンに合わないものを直す」に直した |
| テスト手順で、原稿を書き換えない役（literary-editor・fact-checker）に書き換えをさせていた | A・B | 書き換えは feature-writer が行う手順に直した |

## 通しの実行（サンプル案件）

- 架空のサンプル案件で STEP 1〜10 を通しで回した（`examples/sample-aosagi/reference-run/`）。
- `aco score` の判定は「公開不可」（合計 57 → 60）。了承のない情報 3 件と事実の食い違い 1 件がブロッカーとして残り、清書を作らずに止まった。止める仕組みが設計どおりに働いた。
- 発言の照合 A 28／D 0／E 0、素材にない数値 0。字数は素材の範囲で止め、追加取材の質問 6 問。
- この実行で見つかった食い違い（版情報の書き方、答えの中の【要確認】を発言として照合してしまう点、採点者の食い違い、STEP 6 と STEP 8 の事実確認のファイル、止まったときの stage）を直した。
