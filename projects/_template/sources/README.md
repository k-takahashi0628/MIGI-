# sources（取材資料・原本）

## ここに入れるもの
- 取材の書き起こし（話し手のラベルは `名前：発言`、聞き手は `聞き手：`）
- 先方から届いた資料（企画書・会社資料・メモ・修正指示の原文）
- シリーズの前の記事（公開版の本文）
- 調べた公開情報の控え（URL と確認日を書く）

ファイル名には日付と中身を入れる（例：`2026-11-20_transcript_佐伯.md`、`2026-11-22_先方修正指示.md`）。

## 決まり
- 原本は書き換えない。整えたものが要るときは別のファイルにする
- 書き起こしの誤りに気づいたら、直さずに `work/02_source-audit.md` に注記する
- このフォルダは Git に入れない（`projects/<slug>/` 全体が対象外）。外に共有するときは、本人に範囲を確かめてから
- 他の案件の資料を混ぜない
