# 人間らしい文章とは何か

「人間らしさ」を、誤字や口語をわざと混ぜることだと考えない。人間らしさは、具体的な経験に根ざした判断、書き手の視点、言葉の選び方、情報の取捨選択に出る。

---

## 1. 人間の文章に出るもの

| 出るもの | 文章での現れ方 | 反対に、AI 的な文章で起きること |
|---|---|---|
| 取捨選択 | 書かなかったことがある。一番伝えたいことに字数を使い、他は短い | 全部を同じ重さで並べる。網羅して安心する |
| 判断の跡 | 「なぜこの順番か」「なぜこの言葉か」に答えられる | よくある順番、よくある言葉になる |
| 具体の手触り | 日付・場所・数・固有名・その場の動作や言葉がある | 「さまざまな」「多くの」「大きな」でぼかす |
| 意味のある不均一 | 短い文と長い文、言い切りと迷いが、内容に応じて混ざる | 文の長さも文末もそろう。どの段落も同じ型 |
| 話し手の癖 | 口調・言い回し・考える順番がその人のもの | 全員が同じ優等生の話し方になる |
| 書き手の視点 | 素材のなかから、書き手が見つけた発見がある | 素材の要約か、一般論で終わる |

## 2. 話し手の個性を残す

- 話し手を全員、同じ整った話し方に直さない。考えながら話す人、結論から話す人、例え話の多い人、数字で話す人。その違いが、記事の「この人に会ってみたい」をつくる。
- 残すもの：その人がよく使う言葉、考える順番、言い切り方と迷い方、具体例の選び方。
- 整えてよいもの：言いよどみ、同じ言葉の重複、話があちこちに飛んだ所の順序（意味を変えない範囲）。細かい基準は `knowledge/editorial-patterns/quote-editing.md`。
- 口語を残すかどうかは、媒体のトーンと読み手で決める（`references/derived/A_classification.md` の「条件付き判断」）。経営者向けのビジネス媒体なら書き言葉に寄せ、社員ブログなら話し言葉を残す。どちらでも、話し手が言っていない内容は足さない。

## 3. 地の文の声

- 地の文は、書き手が素材から見つけたことを、読者に手渡す役。話し手の言葉を言い直すだけの地の文は削る。
- 説明しすぎない。読者が感じることを先回りして書かない（「胸が熱くなる」「〜ではないでしょうか」）。事実と発言を置けば、感じるのは読者の仕事。
- 総括を途中に挟まない。「つまり」「このように」でまとめ直すと、前の段落を信用していないように読める。

## 4. 人間らしさを装わない

- わざとくだけさせる、わざと誤字を入れる、わざと文をばらつかせる、は禁止。中身のない文章を「人間っぽく」見せても、読む価値は増えない。
- AI 判定ツールをすり抜けることを目標にしない。目標は、読者にとって読む価値がある記事。
- 書き言葉として素直な文（「〜は〜だ」「〜がある」「始めた」「やめた」）は、飾った文（「〜として機能している」「〜を実現している」）より強いことが多い。

## 5. 書く前に自分に聞くこと

1. この段落は、どの発言・事実から生まれたか。指させるか。
2. 社名と人名を入れ替えても成り立つ文はないか。
3. この記事で、読者が初めて知ることは何か。一文で言えるか。
4. 話し手が読んだとき「自分の言葉だ」と思えるか。
5. 社員・取引先・候補者が読んで、置いていかれる人はいないか。
