## 2. 選んだ発見
- 発見：**同じ麺を毎日作る仕事の中身は、昨日との違いに気づき、その違いを言葉にして班に渡すことだ。** 森下さんは、毎朝の温度と湿度で水を 0.5% 単位で変え、その手ざわりをノートと言葉にして、班の人が次の日に比べられるようにしている。
- 選んだ理由：
  - 候補 3 が依頼の狙い（「毎日同じものを作る仕事」が退屈そうに見られがち：S-16）に、本人の言葉で直接答える。入社理由（S-02）と求める人（S-15）が同じ軸でつながり、記事の始まりと終わりを本人の言葉で結べる。
  - 候補 1 と 2 は、候補 3 の「違いに気づく」「言葉にする」の中身（具体）になる。三つを一つの発見にまとめ、1 と 2 は本文の具体として使う。
  - 置き換えの試しを通らない部分（0.5%、「戻ってこない感じ」、3 年分のノート、触った感じを言葉にさせる教え方、厨房からの転職）が、発見の芯にある。

## 3. 捨てた候補と理由
- No.4：仕事の中身ではなく会社の雰囲気の話で、一番の印象から離れる。決裁者本人の描写で公開の確認も要る。捨てずに「この会社らしい場面」として一問だけ使う候補にする（主題にはしない）。
- No.5：発見としては採らない。失敗とノートを「だから始めた」と因果で書くと、時期の食い違い（2019 年からなら約 7 年、本人は「3年分」）を推測で埋めることになる（C7）。出来事としては山場に使い、因果は本人の答えの範囲（問い「そのあと、何か変えましたか」への答え）にとどめる。

## 4. 発見を支える具体
- 出来事：
  - 朝 6 時に工場に入り、まず温度と湿度を見る（S-05）
  - 2019 年の夏、湿度の高い日にいつもの感覚で水を入れ、生地が柔らかすぎて 300 食分を作り直した（S-09）
  - ノートに毎朝の温度・湿度・加水率・仕上がりを書き、班の人に見せている（S-10・S-11）
  - 新しく入った人に、触った感じを言葉にしてもらう（S-12）
- 数字：加水率 0.5% 単位（S-06）／300 食分（S-09）／ノート 3 年分（S-10）／厨房 6 年・入社 9 年目・班 5 人（S-01・S-04）
- 本人の言葉：
  - 「同じものを毎日作って、それを毎日ちょっとずつ良くしていく仕事をやってみたくなって」（S-02）
  - 「こしが、なんていうか、戻ってこない感じになる」（S-07）
  - 「感覚だけだと、人に渡せないので」（S-11）
  - 「言葉にすると、次の日に比べられるんですよ」（S-12）
  - 「同じことを毎日続けて、昨日との違いに気づける人ですね」（S-15）

## 5. 山場にするエピソード
- S-09 → S-10・S-11：2019 年の夏に 300 食分を作り直した日と、そのあと始めたノート、それを班の人に見せている理由（「感覚だけだと、人に渡せないので」）。
- 注意：
  - いまの素材では 2 文＋3 文しかなく、山場としては薄い。厚くするには追加取材が要る（6 章の 1・2）。
  - 失敗と数量は公開の確認が要る（02 の 6 章）。掲載できない場合の代わりの山場は S-12（新しく入った人に言葉にしてもらう教え方）だが、こちらも場面の具体（誰が、何と言ったか）がない。
  - ノートの期間の食い違いは、本人の確認まで原稿に【要確認】で残す。
