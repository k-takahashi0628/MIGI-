# 構成設計（STEP 4）

<!-- 案件：sample-aosagi ／ 作成日：2026-11-11 ／ 担当：story-architect -->

## 1. 背骨
- 読み手 → 一番の印象 → 中心の発見：製造の仕事に関心のある 20〜30 代に、「同じ麺を毎日作る仕事の中身は、昨日との違いに気づき、その違いを言葉にして班に渡すことだ」と、森下さんの毎朝の判断・失敗のあとのノート・教え方で見せる。

## 2. 先方の構成案の読み（案があるときだけ）
- 先方の構成案はない。依頼メモの意図だけを書く。
- 何を避けたいか：製造の仕事を「毎日同じことの繰り返しで退屈そう」と思われ、20〜30 代の応募の候補から外れること。
- 書き手側の思い込みになりやすい所：「退屈ではない」を地の文で言い張ること。本人は「退屈ではない」とは言っていない。本人の言葉（「毎日ちょっとずつ良くしていく」「昨日との違いに気づける」）と具体（0.5%・ノート・言葉にする教え方）を置き、読み手に判断してもらう。

## 3. 使った型
- 型：社員インタビュー（`knowledge/editorial-patterns/structure-types.md` 1 章）から始め、6 章を 4 章にまとめた。
- 理由：
  - 型の「壁と越え方」（3）と「いまの仕事の中身」（2）の一部（ノート・教え方）は、素材の上では一続きの話（失敗 → ノート → 班に見せる → 新しく入った人に言葉にしてもらう）なので、一つの章にまとめて山場にする。
  - 型の「この会社らしさ」（4）は素材が 1 段落（S-13）だけで、一章にすると薄い。本人の答えは「社長が生地を触って今日はどう？と聞く」で、手で確かめる話の続きとして 2 章の最後に置く。
  - 型の「いまのやりがいと、これから」（5）と「候補者へのメッセージ」（6）は、それぞれ 1 段落ずつなので 4 章にまとめる。
  - 素材が短く、章ごとの答えは 600 字より短い。問いは 1 章 2〜3（`references/derived/A_classification.md` 6-4 の 2）。
  - 章の順は書き起こしの話の順とほぼ同じで、発言の並べ替えは「社長」の段落（S-13）を 2 章へ移す一か所だけ（`drafts/v1_notes.md` に記録する）。

## 4. リード
- 立てる読者の疑問：毎日同じ麺を作る仕事で、毎朝なにを見て、なにを変えているのか。
- 締めで回収する言葉：「毎日」「同じ」「違い」。最後の発言（S-15「同じことを毎日続けて、昨日との違いに気づける人」）でリードの問いに答える。地の文の締めは足さない（最後の発言で十分に答えているため。`knowledge/editorial-patterns/lead-and-ending.md` 2 章）。

### 素材が足りない章

- 1 章：「ちょっとずつ良くしていく」の例がない（追加取材 No.5）。書けないまま進め、【要取材】を置く。
- 使わない素材：S-08（犬の話。本人が「関係ない」と閉じている）。

## 6. 構成の検査
- [x] 一番の印象に関係しない章はない（各章の効き方は 5 章の表）
- [x] 同じことを二つの章で言っていない（2 章＝毎朝の判断、3 章＝読み違えと人への渡し方。ノートは 3 章だけに出す）
- [x] 全章の主語が特定の人たちになっていない（話し手は一人。班の人・新しく入った人・社長は、教わる側・下げられる側として描かない）
- [x] 山場は終盤にある（4 章中 3 章）
- [x] リードの問いと締めが対応している（「毎日」「同じ」→ S-15「同じことを毎日続けて、昨日との違いに」）
- [x] 前の記事と同じ問いを繰り返していない（前の記事なし）
- [x] 理由 → 結論、全体 → 具体、変化 → 支える仕組み の順になっている（選んだ理由 → 毎朝の判断 → 失敗という変化 → ノートと教え方という仕組み → 求める人）
