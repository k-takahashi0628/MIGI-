結論：書き方で誰かを傷つける・分断する文はない。公開を止めるのは、公開の了承がまだない情報 3 件（氏名・冷凍麺のラインの予定・2019 年の作り直しと 300 食分）で、文章では直らず、決裁者・本人の判断待ち（重大度 高 3・中 2・低 1）。了承が取れれば、広報上の問題は残らない。

- `aco audit --project sample-aosagi`：error 0。A1（分断の対）・B1（無策）の兆候なし。B5 は 4 章「それが一番、この仕事に向いてると思います」の 1 件で、本人の意見の範囲（残す。下の表）。
- 台帳：公開禁止の語（confidential）・却下案（rejected）は登録なし。表記ルール RL-1（スタッフ→社員）の違反なし。

## 読む人ごとの受け取り方
| 読む人 | 受け取り方 | 引っかかる所 |
|---|---|---|
| 候補者（20〜30 代・製造に関心） | 毎朝の判断・手の感覚・失敗のあとの工夫が見え、「同じことの繰り返し」という見え方はほどける。班長が教え方を持っていることも伝わる | 2 章「朝6時に工場に入って」を、全員の始業時刻と読む人がいるかもしれない（R-6） |
| 社員（班の人・新しく入った人・ほかの班） | 教わる側として出てくるが、下げられてはいない。ノートを「見せてます」、手ざわりを「言葉にしてもらいます」は、班の中で共有する話として読める | なし |
| 話し手本人 | 書き起こしの言葉どおりで、自分の言葉だと思える。口調も残っている | 2019 年の失敗が実名つきで出る（R-1・R-3） |
| 経営陣（社長＝決裁者） | 「同じ現場の人っていう感じです」は好意的に読める | 「週に1回」の頻度と描写を本人が確かめていない（R-4） |
| 取引先（麺を使う飲食店） | 1 章で「お店の人」の言葉がきっかけとして出る。下に見てはいない | 3 章の作り直しを、品質の不安として読む人がいるかもしれない（R-3）。伝聞の言葉が会社の宣伝文句に見える（R-5） |
| 家族・その他 | 特になし | 特になし |

### R-1 ［重大度：高］ B7 氏名を出す了承がない
- 箇所：リード／該当文「…森下美帆さん【要確認：氏名の掲載（台帳 PD-1）】は、…」、各章の話し手の名前「森下：」
- 指摘：台帳 PD-1 が open のまま。氏名とともに 2019 年の失敗（3 章）も出るので、本人の了承は記事全体に関わる。
- 根拠：台帳 PD-1、`knowledge/editorial-patterns/brand-voice-and-respect.md` 6 章
- 修正案：文章では直さない。了承が取れなければ、リードを「製造課の班長（入社9年目）」、話し手の表記を「班長」にする代案を用意する（事実は変えない）。
- 副作用：名前が出ないと、記事の「この人に会ってみたい」が弱くなる。
- 判断が要る人：本人（採用担当から確認）

### R-2 ［重大度：高］ B7 次の事業（冷凍麺のラインと時期）
- 箇所：章「昨日との違いに気づける人と働きたい」／問い「これからやってみたいことを教えてください。」／該当文「来年、冷凍麺のラインができるんです。2027年の春の予定で。」
- 指摘：次の事業と時期は、負け筋 B7 の典型（出したあとで消せない）。社外に発表済みかが素材から分からない。予定が変わると、記事が会社の約束として残る（B5）。
- 根拠：`work/02_source-audit.md` S-14・6 章、`knowledge/failure-patterns/official-article.md` B7
- 修正案：了承が取れたら、そのまま（本人が「予定」と言っており、言い過ぎではない）。時期だけ出せない場合の代案（本人の言葉の範囲で時期を外す）：
  > 森下：冷凍麺のラインができる予定なんです。その立ち上げに関わりたいです。冷凍だと水の入れ方がまた変わるはずなので。
  （「来年」「2027年の春の予定で」を外す。「予定なんです」は「できるんです」＋「予定で」をまとめた整文で、書き起こしの要素の範囲。ライン自体を出せない場合は、この問いごと外す）
- 副作用：問いごと外すと、4 章の「水の入れ方がまた変わる」（違いに気づく話の前置き）がなくなり、最後の発言が唐突になる。
- 判断が要る人：決裁者（代表）

### R-3 ［重大度：高］ B7・B2 2019 年の作り直しと「300食分」
- 箇所：章「感覚だけでは、人に渡せない」／問い「失敗した経験についても聞かせてください。」／該当文「2019年の夏に、生地が柔らかすぎて、300食分を作り直しました。」
- 指摘：食品メーカーの製造の失敗と数量。広報上は、作り直した（出さなかった）こと・そのあとノートを始めて班に見せていることまで書かれており、意図した工夫として読める（B2 の例外：社員インタビューの「壁と越え方」）。ただし、数量（社内の数字）と失敗を社外に出すことの了承がない。出荷前に作り直したのかは素材にないので、「出荷前に」と足して安心させる直しはしない。
- 根拠：`work/02_source-audit.md` S-09・6 章、`knowledge/failure-patterns/official-article.md` B2・B7
- 修正案：了承が取れたら、そのまま。数量だけ出せない場合の代案：
  > 森下：2019年の夏に、生地が柔らかすぎて、作り直したことがあります。その日は湿度がすごく高くて、いつもの感覚で水を入れちゃったんです。
  （「300食分を作り直しました」→「作り直したことがあります」。【要確認：本人の確認。数量を外した整文】を付ける）
- 副作用：エピソードそのものを外すと、記事に「迷った・失敗した・変えた」場面がなくなり、きれいにまとまりすぎる（B3）。3 章の山場もなくなる。外す前に決裁者へ、この副作用も一緒に示す。
- 判断が要る人：決裁者（代表）、本人

### R-4 ［重大度：中］ B7・A4 社長の描写と「週に1回」
- 箇所：章「水の量は0.5%単位。違いは手で分かる」／問い「アオサギ製麺らしいと感じるのは、どんな場面でしょうか。」／該当文「社長が週に1回、ラインに入るんです。」
- 指摘：決裁者本人の描写。好意的だが、頻度（週に 1 回）は本人の説明だけが根拠で、実際と違えば社内で引っかかる。敬語は社員が社長について話す口調で、過不足はない（A4 の例外）。
- 根拠：`work/02_source-audit.md` S-13、`knowledge/failure-patterns/official-article.md` A4・B7
- 修正案：決裁者が確かめるまで、そのまま【要確認】で残す。頻度が違う場合は、本人に言い直しを確かめたうえで直す（書き手が数字を変えない）。
- 副作用：なし
- 判断が要る人：決裁者（代表）

### R-5 ［重大度：中］ A6・B5 取引先の言葉「アオサギは職人を育てる会社だよ」
- 箇所：章「同じものを毎日作り、ちょっとずつ良くする仕事を選んだ」／問い「そこから製麺に移ったのは、どうしてでしょうか。」／該当文「うちの麺を使っていたお店の人に「アオサギは職人を育てる会社だよ」と聞いて、それで応募しました。」
- 指摘：取引先の人の言葉の伝聞。本人の入社のきっかけとしては事実だが、引用符で目立つため、会社が自分で「職人を育てる会社」と宣伝しているようにも読める。記事の中で「育てる」を支えるのは 3 章の教え方（手ざわりを言葉にしてもらう）だけ。取引先への目配り（A6）としては、店を下に見ていないので問題ない。
- 根拠：`work/02_source-audit.md` S-03、`knowledge/failure-patterns/official-article.md` A6・B5
- 修正案：伝聞として載せてよいかを採用担当に確かめる。載せる場合は、地の文やタイトル・見出しにこの言葉を使わない（会社の自己評価にしない）。v1 はその形になっている。
- 副作用：なし
- 判断が要る人：進行担当（採用担当）

### R-6 ［重大度：低］ C4 「朝6時に工場に入って」を全員の働き方と読まれる
- 箇所：章「水の量は0.5%単位。違いは手で分かる」／問い「毎日のお仕事を、朝から教えてください。」／該当文「朝6時に工場に入って、まず温度と湿度を見ます。」
- 指摘：本人の一日の話として正しいが、候補者は製造職全員の始業時刻と受け取りうる。記事は本人の一日として書かれており、範囲は広げていない。
- 根拠：`knowledge/failure-patterns/official-article.md` C4（範囲）
- 修正案：記事は直さない。募集ページの勤務時間の表記と食い違わないかを採用担当に確かめる。
- 副作用：なし
- 判断が要る人：進行担当（採用担当）
