## 修正指示（feature-writer へ。採った文章の指摘だけ）
1. リード（問いのない段落）：全文を差し替える。
   > 森下美帆さん【要確認：氏名の掲載（台帳 PD-1）】は、ホテルの厨房からアオサギ製麺に移った。入社9年目のいまは、製造課で5人の班の班長を務めている。厨房で毎日違うものを作っていた人が、なぜ同じ麺を毎日作る仕事を選んだのか。その仕事で、毎朝なにを見て、なにを変えているのか。
   - 副作用：「厨房 6 年」「洋食の仕込み」はリードから外れ、1 章の答えだけに出る。
2. 章「水の量は0.5%単位。違いは手で分かる」／問い「アオサギ製麺らしいと感じるのは、どんな場面でしょうか。」→「生地を手で確かめる場面で、アオサギ製麺らしいと感じるのは、どんなときでしょうか。」
3. 章「感覚だけでは、人に渡せない」／問い「そのあと、仕事のやり方で変えたことを教えてください。」→「そのあと、何を変えたのでしょうか。」
   - 「そのあと」は書き起こしの聞き手の言葉どおりに残す（時期の食い違いは本人の確認まで【要確認】のまま）。
4. 章「昨日との違いに気づける人と働きたい」／問い「これからやってみたいことを教えてください。」→「これから、どんな仕事に関わりたいと考えていますか。」
5. 同じ章／問い「最後に、どんな人と一緒に働きたいか教えてください。」→「最後に、一緒に働きたいのはどんな人でしょうか。」
- 答えの段落・見出し・【要確認】【要取材】の印は変えない。
