結論：v2 で変わったのはリードと問いだけで、広報上の新しい問題はない。公開を止めるのは v1 と同じ、了承のない情報 3 件（氏名・2019 年の作り直しと 300 食分・冷凍麺のラインと時期）。どれも文章では直らず、決裁者・本人の判断待ち（重大度 高 3・中 2・低 1。中・低も v1 と同じ）。

- `aco audit --project sample-aosagi`：error 0。A1・B1 の兆候なし。B5 は v1 と同じ 1 件（本人の意見）。
- 台帳：公開禁止の語・却下案の登録なし。RL-1（スタッフ→社員）の違反なし。

## 読む人ごとの受け取り方（v1 からの変化だけ）
| 読む人 | v2 での変化 |
|---|---|
| 候補者 | リードが「なぜこの仕事を選んだのか」を問うので、同じ迷いを持つ読み手が入りやすくなった |
| 話し手本人 | リードから経歴の細部（6 年・洋食の仕込み）が外れ、本人の答えで初めて出る。本人の言葉の扱いは変わらない |
| 経営陣 | 2 章の問いが「手で確かめる場面で」になり、社長の段落が仕事の話の続きとして読める。描写そのものは v1 と同じで、頻度の確認は残る |
| 社員・取引先・家族 | 変化なし |

### R-1 ［重大度：高］ B7 氏名を出す了承がない（v1 R-1 と同じ）
- 箇所：リード「森下美帆さん【要確認：氏名の掲載（台帳 PD-1）】は、…」／全章の話し手名「森下：」
- 指摘・根拠・修正案・副作用：v1 R-1 と同じ（代案：「製造課の班長（入社9年目）」「班長：」）。
- 判断が要る人：本人

### R-2 ［重大度：高］ B7 冷凍麺のラインと「2027年の春」（v1 R-2 と同じ）
- 箇所：章「昨日との違いに気づける人と働きたい」／問い「これから、どんな仕事に関わりたいと考えていますか。」／該当文「来年、冷凍麺のラインができるんです。2027年の春の予定で。」
- 指摘：v1 と同じ。v2 で問いが「どんな仕事に関わりたいと考えていますか」になり、答えの「その立ち上げに関わりたいです」が問いに直接答える形になった。そのぶん、ラインの話を外すと答えが成り立たない（副作用が大きくなった）。
- 修正案：了承が出たらそのまま。時期だけ出せない場合の代案は v1 R-2 と同じ（「冷凍麺のラインができる予定なんです。」）。ライン自体を出せない場合は、問いごと外す。
- 副作用：問いごと外すと、4 章は最後の問い 1 つだけになる。
- 判断が要る人：決裁者（代表）

### R-3 ［重大度：高］ B7・B2 2019 年の作り直しと「300食分」（v1 R-3 と同じ）
- 箇所：章「感覚だけでは、人に渡せない」／問い「失敗した経験についても聞かせてください。」／該当文「2019年の夏に、生地が柔らかすぎて、300食分を作り直しました。」
- 指摘・根拠・修正案・副作用：v1 R-3 と同じ（数量だけ外す代案：「…作り直したことがあります。」。エピソードを外すと B3 と山場の消失）。
- 判断が要る人：決裁者（代表）、本人

### R-4 ［重大度：中］ 社長の描写と「週に1回」（v1 R-4 と同じ）
- 箇所：章「水の量は0.5%単位。違いは手で分かる」／問い「手で確かめる場面で、アオサギ製麺らしいと感じるのは、どんなときでしょうか。」／該当文「社長が週に1回、ラインに入るんです。」
- 修正案：決裁者が確かめるまで【要確認】で残す。
- 副作用：なし
- 判断が要る人：決裁者（代表）

### R-5 ［重大度：中］ 取引先の言葉の伝聞（v1 R-5 と同じ）
- 箇所：章「同じものを毎日作り、ちょっとずつ良くする仕事を選んだ」／問い「そこから製麺に移ったのは、どうしてでしょうか。」／該当文「「アオサギは職人を育てる会社だよ」と聞いて、それで応募しました。」
- 修正案：伝聞として載せてよいかを採用担当に確かめる。地の文・タイトル・見出しには使わない（v2 もその形）。
- 副作用：なし
- 判断が要る人：進行担当（採用担当）

### R-6 ［重大度：低］ 「朝6時」の範囲（v1 R-6 と同じ）
- 箇所：章「水の量は0.5%単位。違いは手で分かる」／問い「毎日のお仕事を、朝から教えてください。」／該当文「朝6時に工場に入って、まず温度と湿度を見ます。」
- 修正案：記事は直さない。募集ページの勤務時間と食い違わないかを採用担当に確かめる。
- 副作用：なし
- 判断が要る人：進行担当（採用担当）
